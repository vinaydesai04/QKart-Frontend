# 🛒 QKart - E-Commerce Storefront

[![Live Demo](https://img.shields.io/badge/demo-online-green.svg)](https://qkart-frontend-inky.vercel.app/)

> A responsive, full-stack e-commerce application featuring product browsing, secure user authentication, and real-time cart management.
> 
## 💡 About The Project

QKart is a modern storefront application built to handle the end-to-end shopping experience. It connects a React-based interactive user interface with a custom Express backend, handling everything from inventory search to secure user sessions. 

### ✨ Key Features
* **Dynamic Product Catalog:** Browse and search through an extensive list of products fetched dynamically from the REST API.
* **Secure Authentication:** User registration and login utilizing JWT Bearer tokens to protect sensitive routes.
* **Stateful Cart Management:** Add items to the cart, update quantities, and calculate totals securely linked to user sessions.
* **Optimized Deployment:** Frontend hosted globally on Vercel, securely communicating with an independent Node.js backend hosted on Render.
